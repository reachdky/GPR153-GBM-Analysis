# legacy/ (superseded)

These are the scripts as posted at initial submission (commit `e0d6bb5`, 2026-07-06, planned tag
`v1-submitted`), moved here with `git mv` and not modified. They are kept for the record and are not used by
the revised analysis (`pipeline/`, run with `run_all.sh`; see the top-level README).

The value each submitted claim had in these scripts' outputs, and its revised value, is in
`revision/tables/S9_Table.csv` (generated by `pipeline/x02_claims_ledger.py`).

## Scripts named in the editor's decision letter (PONE-D-26-34494)

| Script | Editor's comment (decision letter section) | Revised analysis |
|---|---|---|
| `09_correlation_analysis.py` | Screens genes against a target with Pearson correlation, a prefilter of \|r\| >= 0.3, sorting by absolute Pearson r and at most 100 genes; no Benjamini-Hochberg correction of a genome-wide result; cannot establish a 59,569-gene Spearman ranking with genome-wide FDR (Section 2) | `pipeline/a11_screen.py` |
| `10_survival_analysis.py` | Applies `mannwhitneyu` to observed survival times ("log-rank test approximation"); the censoring indicator is not used; not a log-rank test (Section 4) | `pipeline/a21_km.py` |
| `cox_regression_v2.py` | Uses `CoxPHFitter(penalizer=0.1)`; penalization not disclosed in the manuscript (Section 4) | `pipeline/a20_cox.py` (penalizer 0) |
| `12_differential_expression.py` | Group means, log ratios, independent-samples t-tests and FDR afterwards; does not implement DESeq2 or ComBat-seq (Section 5) | `pipeline/a59_de_inputs.py`, `a60_deseq2.py`, `a61_pydeseq2.py` |
| `14_predictive_modeling.py` | 70/30 split, 365-day threshold and TP53 instead of the 80/20 split, median-survival outcome and TERT stated in the Methods (Section 6) | `pipeline/a50_survival_forest.py` |
| `11_pathway_analysis.py` | Submits up to 500 genes to Enrichr and uses `GO_Biological_Process_2021`, not the top 10 genes and 2023 libraries stated; no ranked-list GSEA (Section 7) | `pipeline/a40_enrichment.py`, `a41_camera.py` |
| `16_generate_figure1.py` | The README says it makes a scatterplot and volcano plot; it makes expression boxplots (Section 9, item 5) | `pipeline/f10_main_figures.py` |
| `17_generate_figure2.py` | The README says it makes the Kaplan-Meier figure; it makes Pearson correlation plots and a correlation heatmap (Section 9, item 6) | `pipeline/f10_main_figures.py` |
